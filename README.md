## About me

I’m **Keerit Kapoor**, a **Computer Science student at Toronto Metropolitan University** with an interest in cybersecurity, software development, and the overlap between AI and security.

I like understanding what happens beneath the interface: how an application handles data, where trust boundaries break down, and what a useful fix looks like. My projects cover secure Python code, web and API security, and phishing awareness. I care about explaining the reasoning as much as showing the result.

**My next direction:** move from individual assessments into complete tools that collect evidence, test security controls, and make findings easier to act on.

### Next-build roadmap

**01 / AI-assisted security triage lab** · Planned  
A lab that brings together security events, detection rules, and an AI assistant that drafts incident summaries linked to their source evidence. The goal: keep investigation steps traceable, require human review, and measure false positives instead of treating every alert as a threat.

<sub>Python · Wazuh · Sigma · FastAPI · local LLMs · evaluation datasets</sub>

**02 / API security testing platform** · Planned  
A containerised test application and repeatable test suite for authentication, object-level access control, input validation, and rate limits. The goal: compare vulnerable and hardened behaviour, then generate a clear report in a CI workflow.

<sub>FastAPI · PostgreSQL · Docker · pytest · OWASP ZAP · GitHub Actions</sub>

**My portfolio is the home for the work:** [keeritkapoor.com ↗](https://keeritkapoor.com) — project walkthroughs, technical decisions, and case studies as the builds take shape.
